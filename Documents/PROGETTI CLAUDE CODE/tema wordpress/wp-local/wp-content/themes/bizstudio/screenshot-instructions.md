# BizStudio Theme Screenshot Instructions

## Required Dimensions

- **Width:** 1200px
- **Height:** 900px
- **Format:** PNG
- **Filename:** `screenshot.png` (placed in theme root)

WordPress uses this file for the theme preview in **Appearance > Themes**.

## What to Include

The screenshot should showcase the theme's key visual features:

1. **Header** -- Show the default header preset with logo, navigation, and action icons (search, wishlist, cart)
2. **Hero Section** -- The front-page hero with headline, description, and CTA button
3. **Product Grid** -- A portion of the product grid showing 3-4 product cards with images, prices, and badges
4. **Color Scheme** -- Use the default purple primary color (#8367C7) throughout
5. **Typography** -- Use Inter font to match the theme default

## Recommended Setup

1. Install the theme on a local WordPress + WooCommerce instance
2. Import sample WooCommerce products (or use WC's built-in sample data)
3. Set up the front page as a static page
4. Configure a primary menu with 3-4 items
5. Upload a logo or use the text-based site title
6. Take a browser screenshot at 1200px viewport width
7. Crop to exactly 1200x900px

## Tips

- Use high-quality product images for visual appeal
- Ensure the promo bar is visible at the top
- Show at least one product badge (sale or new)
- The screenshot should look clean and professional
- Avoid showing the browser chrome or address bar
- Dark mode should NOT be active (use the default light theme)

## Tools

- **Browser DevTools:** Set viewport to 1200px width, take full-page screenshot, crop
- **Figma/Photoshop:** Design a mockup at exact dimensions if preferred
- **macOS:** `Cmd+Shift+4` to select area, or use the Screenshot app

## WordPress Guidelines

Per the WordPress Theme Review guidelines:
- The screenshot must accurately represent the theme
- It should not include content that misleads the user
- Recommended to keep file size under 1MB (use PNG optimization tools like TinyPNG)
